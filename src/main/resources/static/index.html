Why this is not a scanner dashboard

A scanner reports a version and a CVSS score. It cannot tell you whether the affected version is actually running, whether the service is reachable, whether anyone is exploiting it, or whether it matters. This agent gathers that evidence, and every step is recorded.

It proposes; a human decides. A consequential action cannot be executed without approval, and that is enforced by the runtime rather than by asking the model nicely.
